# Retail Sales & Profitability Analysis

## Project Overview
This project focuses on analyzing retail sales and profitability using Microsoft Excel. An interactive dashboard was developed to explore sales performance, profit trends, product performance, and regional sales.

## Tools & Technologies
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Excel Formulas and Slicers

## Dataset
- Original records: 10,000
- Records after cleaning: 9,985
- Columns: 21
- Dataset type: Synthetic practice dataset

## Data Cleaning
- Removed duplicate records.
- Handled missing and inconsistent values.
- Standardized text fields and data formats.
- Validated dates and financial values.

## Key Performance Indicators
- Total Sales: ₹11.01 Crore
- Total Profit: ₹2.76 Crore
- Profit Margin: 25.05%
- Total Orders: 9,985
- Total Customers: 2,460

## Dashboard Features
- 5 KPI cards
- 8 interactive charts
- 5 slicers for filtering and analysis

## Key Insights
- Technology was the highest-selling category.
- The West region recorded the highest sales.
- Technology generated the highest profit among categories.
- Order status and payment methods showed a relatively balanced distribution.
